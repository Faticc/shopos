# ShopOS 2

Машина OpenComputers, на которой нет ничего, кроме магазина. OpenOS не нужна:
BIOS грузит `/init.lua`, тот поднимает магазин и держит его запущенным.

## Как торгует игрок

1. Встаёт на PIM — магазин узнаёт ник и показывает его счёт.
2. Кладёт в инвентарь монеты `customnpcs:npcMoney` и жмёт **ПОПОЛНИТЬ** —
   монеты уходят из инвентаря в МЭ, на счёт ложится их стоимость (1 монета =
   1 $ при `coinValue = 1`).
3. Выбирает раздел (мод) или ищет по названию с клавиатуры, открывает товар,
   ставит количество (±1/10/64 или МАКС), жмёт **КУПИТЬ** — предмет приходит
   из МЭ в инвентарь, со счёта списывается цена.

Больше в экономике ничего нет: ни продажи магазину, ни обменников, ни
вывода денег обратно в монеты.

## Откуда товары и цены

* **Товары** — всё, что лежит в МЭ-сети под PIM, кроме стопок с NBT и самих
  монет. Витрина перечитывает МЭ при входе игрока, после покупки и раз в
  30 секунд.
* **Цены** — поле `min` из выгрузки цен клиента (`dumps/prices.jsonl`).
  Предмет, которого в выгрузке нет, не продаётся. Цена штуки в монетах —
  `min × rate × markup`; `rate` и `markup` правятся в `cfg/shop.cfg` без
  пересборки каталога. При `rate = 100`: алмаз 50 $, медный слиток 10 $,
  земля 0.004 $.
* **Иконки** — из каталога `assets/shop16.bin` (выгрузка iconexporter),
  16×8 ячеек. Если у мета нет своей иконки, берётся иконка соседнего.

Цены и иконки лежат в одном файле `data/catalog.bin` (2.1 МБ, 6202 предмета
с ценой). Собрать заново после новой выгрузки цен:

```bash
python tools/shopcat.py "C:\Users\User\McSkill\clients\Industrial_1.7.10\dumps\prices.jsonl" assets/shop16.bin shopos/data/catalog.bin
```

## Деньги

Счёт игрока — `/var/wallet/<ник>`, целое число в сотых долях монеты.
Дешёвое стоит доли сотой, поэтому округляется вверх только итог покупки:
64 земли — 0.26 $, а не 64 × 0.01.

Покупка сначала списывает деньги и пишет счёт на диск, потом выдаёт. Если
в инвентарь влезло не всё (или товар кончился), недоданное возвращается на
счёт. Все операции пишутся в `/var/ledger.log`.

Пока на PIM стоит игрок, клики других игроков по экрану не проходят.

## Файлы

```
/init.lua           ядро: видеокарта, require, перезапуск при падении
/sys/disk.lua       файлы поверх filesystem, чтение кусками по 2 КБ
/sys/gfx.lua        рисование: буфер видеопамяти, текст, иконки
/sys/catalog.lua    цена/название/иконка по ключу предмета
/sys/storage.lua    МЭ-интерфейс и PIM
/sys/wallet.lua     счета и журнал
/sys/shop.lua       экраны и логика магазина
/cfg/shop.cfg       настройки
/data/catalog.bin   каталог
/var/               счета, журнал, /var/crash.log
```

## Железо

| | |
|---|---|
| корпус, видеокарта, монитор | 3-й уровень (экран 160×50, иконки) |
| память | 1024 КБ хватает: в памяти только индекс каталога (48 КБ) и то, что есть в МЭ |
| диск | 3-й уровень (4 МБ): каталог 2.1 МБ |
| PIM | стоит на МЭ-интерфейсе: выдача `UP`, приём монет `DOWN` |
| интернет-карта | только на время установки |

## Установка

На машине с OpenOS и интернет-картой:

```bash
wget -f https://raw.githubusercontent.com/Faticc/shopos/main/install.lua /tmp/i.lua && /tmp/i.lua --clean
```

и `reboot`. `--clean` стирает OpenOS и прежний ShopOS (`/os`). `--dry`
показывает, что будет записано. `cfg/shop.cfg`, если он уже есть на диске,
не перезаписывается. Каталог качается потоком прямо в файл — в память
машины он не поднимается.

## Проверка без игры

Из каталога `shopos/`:

```bash
lua test/run.lua out "on:Steve,coins:300,touch:150:2,touch:40:10,shot:item,touch:60:31,shot:bought"
```

```bash
python ../tools/renderscreen.py out/item.json item.png
```

`test/run.lua` — песочница OpenComputers без OpenOS, gpu с видеобуферами,
диск из этого каталога (чтение по 2 КБ, `/var` уходит в папку вывода) и
поддельные МЭ и PIM с теми же вызовами, что у модов. Сценарий с кириллицей
передавайте файлом: `@script.txt`.
